## 🏨 Current Mission: ReadyRoom

> Building a centralized hotel booking ecosystem where customers, hotel
> operations, administrators, and partners work from one reliable source of truth.

ReadyRoom is being developed as a production hotel platform supporting:

- Customer booking through web and Flutter mobile applications
- Transit and Full Day room-booking services
- Centralized Laravel API and MySQL database
- Operational booking management through an admin panel
- Room monitoring, booking calendar, and reporting
- Firebase push notifications for mobile customers
- Customer account, OTP, and booking history
- Hotel partner and extranet development
- Deployment using Ubuntu VPS and Nginx
